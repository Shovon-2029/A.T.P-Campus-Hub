# 🎓 A.T.P. Campus Hub: Assistance & Tracking Protocol.
The AI-Powered "Super-App" for Student Safety, Wellbeing, and Inclusive Navigation.
🌟 The Vision
Campuses are micro-societies. If we can solve the challenges of safety, mental health, and accessibility here, we can scale these solutions to cities. A.T.P. Campus Hub brings everything a student needs—from budget food to emergency safety—under one roof.

🚩 Problem Statement
Students, especially those in hostels, face a "fragmented campus experience." Information about schedules is in one place, safety reporting is non-existent, and mental health support is often stigmatized or hard to reach.
Our Solution: A unified AI ecosystem that uses Geofencing, Sentiment Analysis, and Real-time Mapping to foster a resilient student community.

✨ Core Features (The USPs)
🚨 1. The "Red Zone" & Safety Net (Crisis Mapping)
Anonymous Reporting: Students can upload photo/video evidence of hazards or harassment zones anonymously.

Geofencing Alerts: Using Mapbox, the app triggers a haptic/push notification when a student enters a "High-Complaint Red Zone."

One-Tap SOS: Immediate GPS broadcast to Campus Security, Parents, and Local Police.

🤖 2. AI Student Concierge & Mental Health
Budget-Friendly Navigator: AI suggests real-time, low-cost food, stationary, and medicine shops near the user's GPS location.

Sentiment Monitoring: If the AI detects patterns of distress (e.g., searching for specific medications or expressing hopelessness), it triggers a "Wellbeing Nudge" or offers a direct line to a counselor.

Study Architect: AI manages exam timetables and extra-curricular balances with proactive reminders.

🗺️ 3. Inclusive Campus Navigation
Live Maps: Interactive schedule-synced maps for classes and events.

Accessibility First: Inclusion-by-design UI with high contrast and screen-reader support.

🛠️ Tech Stack
Frontend: Next.js / React (PWA)

Backend: Node.js / Supabase (Real-time DB)

AI/ML: Gemini API / OpenAI API (Sentiment Analysis & Recommendations)

Maps: Mapbox GL JS (Geofencing & Red Zone visualization)

Authentication: Student ID + Org Code validation
